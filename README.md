# Analyses and data for: McCahon, S.L., Conway, C.J., Morrissey, C.A., Christie, K.S. Cropland cover, neonicotinoids, and drought reduce shorebird refueling during migration. Biological Conservation, In Review
This repository provides the data and R code to reproduce the analyses from:  McCahon, S.L., Conway, C.J., Morrissey, C.A., Christie, K.S. Cropland cover, neonicotinoids, and drought reduce shorebird refueling during migration. Biological Conservation, In Review

## Data Folder Description
1. The dataset `Shorebird-and-Invert_2023.csv` contains data for the first SEM in the article (combined 2023 bird and invertebrate dataset). 
2. The dataset `Shorebird_2021-2023.csv` contains data for the second SEM in the article (2021-2023 bird dataset).
3. The dataset `Invert_2023.csv` contains data for the third SEM in the article (2023 invertebrate dataset).

## Code Folder Description
1. The file `Shorebird and Invert 2023_SEM.R` runs the code for SEM 1 (complete dataset of shorebirds and invertebrates in 2023).
2. The file `Shorebird 2021-2023_SEM.R` runs the code for SEM 2 (all shorebirds from 2021-2023).
3. The file `Invert 2023_SEM.R` runs the code for SEM 3 (all invertebrates from 2023).
4. The file `Spring Invert 2023_SEM.R` runs the code for SEM 4 (spring invertebrates from 2023 only).
